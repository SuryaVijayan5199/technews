TechCrest Light & Dark Application Asset Pack
===============================================

--------------

- light/techcrest-symbol-light.png

DARK VERSION
------------
Use on navy/black/dark UI surfaces.
- dark/techcrest-primary-dark.png

APP ICONS
---------
512x512 PNG + WebP variants are included.

FAVICONS
--------
Light and dark favicon sets are included from 16px to 512px.

RECOMMENDED UI RULES
--------------------
Light UI:
  Primary logo / dark text + blue-purple mark.

Dark UI:
  Reverse logo / light text + blue-purple mark.

Never place the light logo treatment on a dark surface if contrast is insufficient.
Never place the dark wordmark directly on a busy image without a solid/controlled background.
